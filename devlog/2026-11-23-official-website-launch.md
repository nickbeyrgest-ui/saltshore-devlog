# November 23, 2026 — The official Saltshore website goes live

**Language:** **English** · [Русский](2026-11-23-official-website-launch.ru.md)

The Saltshore project now has an official landing page:

**[marvollostudio.com](https://marvollostudio.com/)**

This is the project's website and introduction hub, not an announcement of a downloadable game. Saltshore remains in active development.

## What this changes

The website gives newcomers a separate place to discover the game. This GitHub journal provides a more detailed record of verified development work.

The website's **Development Log** links are intended to point here. They will only be usable by the general public once this repository passes its publishing review and is made public.

## What has not changed

There is still **no public game build**. A separate release milestone will be announced when a tested build is available.
