# Медиа Saltshore

Папка для изображений, безопасных для возможного публичного раскрытия репозитория.

## Планируемые кадры

- `screens/inventory-equipment.png`
- `screens/crafting-screen.png`
- `screens/character-stats.png`
- `screens/world-overview.png`

Нужны **реальные** игровые скриншоты. Не копировать сырые архивы референсов, личные сохранения, скрытые сюжетные материалы, API-ключи, debug-логи и скриншоты рабочего стола.

Перед публикацией новых изображений проверить право распространения каждого ассета. Правила: [SCREENSHOT_GUIDE.md](../docs/SCREENSHOT_GUIDE.md).
