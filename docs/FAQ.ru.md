# Частые вопросы

**Язык:** [English](FAQ.md) · **Русский**

### Можно скачать Saltshore?

Пока нет. Рабочий внутренний прототип существует, но **публичной игровой сборки нет**.

### Где почитать об игре?

Официальный сайт — **[marvollostudio.com](https://marvollostudio.com/)**. В этом репозитории собраны более подробные записи о разработке.

### На каком движке создаётся игра?

RPG Maker MZ с собственными JavaScript-модулями и игровыми системами.

### Насколько игра готова?

Автор принял три переработанные стартовые локации и ряд систем интерфейса и исследования. Есть также функциональный боевой прототип, графика и анимации которого требуют доработки. **О завершении полноценной публичной сюжетной главы не объявлялось.**

### Какие механики планируются?

Исследование, крафт, развитие персонажа, сюжетные решения, отношения, ветвящиеся задания и новые локации. Часть технических систем уже работает, но значительная доля сюжетного контента ещё создаётся.

### Игра будет бесплатной?

Да. Дополнительный сюжетный контент не будет закрыт за добровольной поддержкой.

### Для какой аудитории игра?

Для совершеннолетних игроков 18+. Игра затрагивает взрослые темы, подробности будут указаны для конкретных будущих сборок.

### Используется искусственный интеллект?

Да. Для планирования, кода, тестов, документации и графических экспериментов используются ChatGPT, OpenAI Codex, OpenCode, ComfyUI и локальные/open-weight модели. Художественное направление и итоговую приёмку определяет автор.

### Можно посмотреть исходники?

Основной репозиторий игры остаётся **приватным**. Этот дневник — выборочная витрина разработки, а не открытые исходники.
