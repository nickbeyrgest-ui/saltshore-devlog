# Связь GitHub-дневника с официальным сайтом

**Язык:** [English](SITE_INTEGRATION.md) · **Русский**

Официальный сайт Saltshore опубликован 23 ноября 2026 года:

**[marvollostudio.com](https://marvollostudio.com/)**

GitHub-дневник ведётся отдельно и предназначен для кнопки **Development Log** на сайте:

`https://github.com/nickbeyrgest-ui/saltshore-devlog`

## Доступ и публикация

Сайт может работать публично, пока репозиторий GitHub остаётся приватным. Пока видимость не изменена на **Public**, посетители без доступа могут получать 404 по ссылке дневника.

Перед открытием дневника необходимо проверить полную историю Git, изображения, права на ресурсы и приватные метаданные. **Основной репозиторий игры должен остаться приватным.**

## Согласованность

- Игра **находится в разработке**, публичной сборки ещё нет.
- Сведения о релизе появятся только после фактической приёмки.
- Используются согласованные игровые скриншоты и точные описания, не имитации геймплея.
- Сайт и GitHub могут делиться проверенными новостями, но не должны автоматически копировать закрытые исходники и личный дневник идей.
