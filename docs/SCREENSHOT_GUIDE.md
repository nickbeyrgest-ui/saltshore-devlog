# Скриншоты для публичного дневника

Цель — показать **реальную игру**, а не рекламный мокап или генерацию, выдаваемую за внутриигровой кадр.

## Первый комплект

| Файл | Что показать |
| --- | --- |
| `media/screens/inventory-equipment.png` | Окно инвентаря/экипировки, Миру, предметы |
| `media/screens/crafting-screen.png` | Рецепты и читаемый интерфейс создания |
| `media/screens/character-stats.png` | Экран характеристик героини |
| `media/screens/world-overview.png` | Мир, атмосферу и взаимодействия |

## Правила

- PNG, исходное соотношение сторон, без чужих окон и персональных данных.
- Без debug-оверлеев, временных ошибок, сломанного текста и спойлеров.
- Изображения должны происходить из реально запущенного проекта или из проверенного утверждённого арта с **честной подписью** «концепт».
- Права на каждое изображение проверяются отдельно, особенно если оно содержит сторонние или лицензированные элементы RPG Maker MZ.
- Перед публикацией владельцу показываются превью. Не копировать всю папку `references/` из приватной игры.
